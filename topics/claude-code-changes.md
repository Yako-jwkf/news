# Claude Code の変更

要約: Claude Code の版ごとの変更のうち、test(Yako-jwkf/test)の仕組みに関わる分野(フック・権限・設定・スキル・サブエージェント・サンドボックス・クラウド・定期実行・CLAUDE.md)のものだけを並べる。全部の変更は公式の変更履歴(https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md)にある。
